# 若狭電力株式会社

若狭県の架空の電力会社「若狭電力株式会社」の設定資料と、GitHub Pages向けの紹介サイトです。サイトは2011〜2016年ごろの企業・自治体サイトをイメージした、シンプルな構成です。

## ページ

- `index.html` — トップページ
- `company.html` — 会社案内
- `plant.html` — 若狭渡原子力発電所
- `supply.html` — 電力供給状況
- `renewable.html` — 再生可能エネルギー
- `disaster.html` — 防災・停電情報
- `wakaden_settings.txt` — プレーンテキストの設定資料
- `styles.css` — 全ページ共通のデザイン

## GitHub Pages

リポジトリの **Settings → Pages** で、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` に設定すると公開できます。

供給状況は平常時の初期表示を「安定供給中」とし、需給率など未設定の数値は掲載していません。このサイトは架空の設定を紹介するファン制作ページです。
